# Краткое описание решения

> Текст для поля «Краткое описание решения» в личном кабинете (до 1000 символов).

Модуль безопасности персональных данных — высоконагруженный прокси для LLM, который идентифицирует, маскирует и демаскирует персональные данные (ПД) в цепочке «система-потребитель → LLM». Поддерживает 17 типов ПД: ФИО, даты, паспорт, гражданство, адрес, email, телефон, ИНН, карта, CVV, PIN и др. Маскирование — полное скрытие (все символы → *), демаскирование по payload_id с сохранением позиций. Гибкая настройка систем и типов ПД через config.json. Производительность: RPS ~2401, latency p99 ~139ms, обработка до 100 000 токенов. Дополнительно: токенизация, документы кроме паспорта РФ, контекстное маскирование. Безопасность: ПД не попадают в логи и метрики.
