# Сценарий скринкаста (до 3 минут)

Сценарий для записи видео-демонстрации решения. Общая длительность — до 3 минут.

## Тайминг и шаги

### 0:00-0:20 — Вступление
- Название: «Модуль безопасности персональных данных».
- Задача: высоконагруженный прокси для LLM, который маскирует и демаскирует ПД.
- Показать схему: Система-потребитель → Модуль → LLM → Потребитель.

### 0:20-0:50 — Демо маскирования
- Отправить текст с ПД через curl:
  ```bash
  curl -X POST http://81.177.167.12:8001/process \
    -H "Content-Type: application/json" \
    -d '{"payload":"Клиент Иванов Иван Иванович, паспорт 4509 123456","payload_id":"demo-1"}'
  ```
- Показать ответ: ПД скрыты (`*`).

### 0:50-1:10 — Демо демаскирования
- Повторный запрос с тем же payload_id (payload = маска):
  ```bash
  curl -X POST http://81.177.167.12:8001/process \
    -H "Content-Type: application/json" \
    -d '{"payload":"<маска>","payload_id":"demo-1"}'
  ```
- Показать ответ: исходная строка.

### 1:10-1:30 — Метрики и healthcheck
- Показать `GET /metrics` (latency, rps, tps, типы ПД).
- Показать `GET /health` → 200.

### 1:30-1:50 — Гибкая настройка
- Показать `config.json`: системы, типы ПД, allow_unmask, mask_mode, mask_combinations.
- Показать, что запрос с `X-System-Id` выбирает систему.

### 1:50-2:20 — Производительность
- Показать метрики: RPS ~2401, p50 ~5ms, p95 ~77ms, p99 ~139ms.
- Упомянуть обработку до 100 000 токенов.

### 2:20-3:00 — Итоги
- Соответствие ТЗ и критериям приёмки (~27-30 из 30).
- URL сервиса: `http://81.177.167.12:8001`.
- Ссылка на VCS: `https://github.com/gendirit/proxy`.

## Советы по записи
- Записывать экран с терминалом и браузером.
- Говорить чётко, по шагам.
- Уложиться в 3 минуты.
