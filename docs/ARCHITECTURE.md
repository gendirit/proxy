# Схема архитектуры решения

> **Формат маскирования.** В исходном ТЗ указан **частичный** формат (например, `И. И. И.`, `45** ****56`). Организаторы позже решили маскировать **полностью** — все символы ПД скрываются (`*`). Наш сервис реализует **полное скрытие**.

## Общая схема

```
Система-потребитель ──► Модуль безопасности ПД ──► LLM
        ▲                        │
        └────────────────────────┘
              (демаскирование ответа)
```

1. **Система-потребитель** отправляет запрос с ПД в модуль.
2. **Модуль** маскирует ПД и передаёт безопасный текст в LLM.
3. **LLM** возвращает ответ.
4. **Модуль** демаскирует ответ (если разрешено) и возвращает системе-потребителю.

## Компоненты модуля

| Компонент | Файл | Назначение |
|-----------|------|-----------|
| API-сервис | `main.py` | FastAPI: `POST /process`, `GET /metrics`, `GET /health`. |
| Детекторы ПД | `detectors.py` | Регэксп-детекторы 17 типов ПД, разрешение пересечений, маскирование/токенизация. |
| Хранилище | `store.py` | SQLite-хранилище записей (общее для воркеров), батчинг записи. |
| Конфигурация | `config.json` | Системы, типы ПД, флаг демаскирования, mask_mode, mask_combinations. |

## Поток обработки запроса

### Маскирование (первый запрос с новым payload_id)

1. `POST /process` с `{payload, payload_id}`.
2. `ProcessService.process()` — быстрый путь из кэша (если результат уже есть).
3. `_detect()` — определение типов ПД (спаны).
4. `apply_spans()` — маскирование (полное скрытие `*`).
5. Сохранение записи (оригинал ↔ маска) в SQLite.
6. Ответ: `{"result": "<маска>"}`.

### Демаскирование (второй запрос с тем же payload_id)

1. `POST /process` с `{payload: <маска>, payload_id}`.
2. Поиск записи по `payload_id`.
3. Возврат исходной строки.
4. Ответ: `{"result": "<исходная строка>"}`.

## Настройка систем и типов ПД

`config.json`:
```json
{
  "default_system": {"enabled": true, "pii_types": ["ALL"], "allow_unmask": true,
                     "mask_mode": "mask", "mask_combinations": []},
  "systems": [
    {"name": "crm-assistant", "enabled": true, "pii_types": ["ALL"],
     "allow_unmask": true, "mask_mode": "mask", "mask_combinations": []}
  ]
}
```

- `X-System-Id` выбирает систему.
- `pii_types` — типы ПД для маскирования.
- `allow_unmask` — разрешение демаскирования.
- `mask_mode` — mask (звёздочки) или tokenize (токены).
- `mask_combinations` — контекстное маскирование (маска при комбинации типов).
