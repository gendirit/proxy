## Критические риски

| Риск | Влияние | Митигация |
|------|---------|-----------|
| RPS ~989 < 1000 | Невыполнение SLA | Оптимизация детекторов, кэширование, увеличение воркеров |
| Полное маскирование vs эталон (частичное) | Снижение метрики точности | Уточнить формат маскирования по эталону |
| Двухкомпонентное ФИО может не маскироваться | Пропуск ПД | Добавить регэксп для 2-словных ФИО с контекстом |
| `_DL_RE` с широким разделителем | Ложные срабатывания | Сузить разделитель, добавить контекст |
| Сетевой доступ к удалённому эндпоинту | Невозможность проверки контракта | Локальная проверка через curl |

## Ближайшие шаги (приоритет)

1. Достичь RPS ≥ 1000 (оптимизация детекторов, кэширование).
2. Проверить контракт на удалённом эндпоинте.
3. Добавить тест на двухкомпонентное ФИО.
4. Расширить датасет нагрузочного теста до ~20 кейсов.
5. Реализовать маскирование только при нескольких типах ПД.
