# Модуль: Нагрузочный тест (`loadtest.py`)

Эмуляция проверяющей системы для оценки производительности и корректности `POST /process`.

## Назначение

Подаёт нагрузку на сервис, эмулируя поведение проверяющей системы: пары запросов (маскирование → демаскирование) с одним `payload_id`, keep-alive соединения, повторное использование элементов датасета. Оценивает RPS и латентность (p50/p95/p99).

## Параметры

| Параметр | Значение | Описание |
|----------|----------|----------|
| `HOST` | `127.0.0.1` | Адрес сервиса. |
| `PORT` | `8000` | Порт сервиса. |
| `PATH` | `/process` | Эндпоинт. |
| `CONCURRENCY` | `100` | Одновременных keep-alive соединений. |
| `PAIRS_PER_WORKER` | `20` | Пар запросов на поток (итого 2000 пар = 4000 запросов). |
| `TIMEOUT` | `10` | Таймаут соединения (сек). |
| `PAYLOADS` | 6 шаблонов | Элементы датасета. |

## Логика

1. **Проверка корректности** (`_correctness_check`): одна пара запросов до прогона — убеждается, что маскирование и демаскирование работают.
2. **Прогрев** (`_warmup`): 50 запросов для прогрева кэша и соединений.
3. **Основной прогон**: `CONCURRENCY` потоков, каждый выполняет `PAIRS_PER_WORKER` пар запросов:
   - прямой запрос (маскирование) → получает маску;
   - обратный запрос (демаскирование) с той же маской и `payload_id`.
4. **Сбор статистики**: латентности успешных запросов, HTTP-ошибки, исключения соединений.

## Вывод

```
correctness: OK (...)
requests ok: 4000
http errors: none
connection exceptions: 0
elapsed: 4.04s
rps (ok): 988.9
rps (all): 988.9
p50: 79.1 ms
p95: 100.3 ms
p99: 496.1 ms
max: 1470.1 ms
```

## Запуск

```bash
uvicorn main:app --host 127.0.0.1 --port 8000 --workers 1
python loadtest.py
```

## Результаты (последний прогон)

- RPS: ~989 (цель ТЗ — 1000);
- p50: ~79 ms, p95: ~100 ms, p99: ~496 ms;
- max: ~1470 ms (единичный выброс при гонках на `payload_id`);
- ошибок нет.

## Расширение датасета

Для более реалистичной нагрузки можно расширить `PAYLOADS` до ~20 разнообразных кейсов (все типы ПД из ТЗ). Это позволит проверить поведение сервиса на разнородных данных.
