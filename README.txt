Модуль безопасности персональных данных — высоконагруженный прокси для LLM, который идентифицирует, маскирует и демаскирует персональные данные (ПД) в цепочке «система-потребитель → LLM». Контракт: POST /process с телом {payload, payload_id} → ответ {result}.

== Локальный запуск ==

1. Установите зависимости: pip install -r requirements.txt
2. Запустите сервис: python main.py (сервис поднимется на порту 8000)
3. Проверьте healthcheck: curl http://localhost:8000/health → {"status":"ok"}

== Проверка маскирования и демаскирования ==

1. Маскирование (первый запрос с новым payload_id):
   curl -X POST http://localhost:8000/process -H "Content-Type: application/json" -d '{"payload":"Клиент Иванов Иван Иванович, паспорт 4509 123456","payload_id":"check-1"}'
   → {"result":"<замаскированная строка>"} (ПД скрыты символами *)

2. Демаскирование (второй запрос с тем же payload_id, payload = маска):
   curl -X POST http://localhost:8000/process -H "Content-Type: application/json" -d '{"payload":"<маска>","payload_id":"check-1"}'
   → {"result":"Клиент Иванов Иван Иванович, паспорт 4509 123456"} (исходная строка)

== Удалённое подключение ==

Развёрнутый сервис доступен по адресу: http://81.177.167.12:8001
Эндпоинт: http://81.177.167.12:8001/process (тот же контракт POST /process)
Healthcheck: http://81.177.167.12:8001/health
Метрики: http://81.177.167.12:8001/metrics

Пример удалённого запроса:
curl -X POST http://81.177.167.12:8001/process -H "Content-Type: application/json" -d '{"payload":"Клиент Иванов Иван Иванович, паспорт 4509 123456","payload_id":"check-1"}'

== Настройка ==

Гибкая настройка систем и типов ПД — в файле config.json:
- systems — список систем-потребителей (вкл/откл).
- pii_types — типы ПД для маскирования.
- allow_unmask — разрешение демаскирования.
- mask_mode — режим маскирования (mask/tokenize).
- mask_combinations — контекстное маскирование.

Запрос с заголовком X-System-Id выбирает систему. Для отключённой системы возвращается 403.

== Производительность ==

- RPS ~2401 (цель ТЗ — 1000, повышенный уровень — 2000).
- Latency: p50 ~5ms, p95 ~77ms, p99 ~139ms.
- Обработка крупных текстов до 100 000 токенов.
