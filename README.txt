Модуль безопасности персональных данных — прокси для LLM с контрактом POST /process ({payload, payload_id} → {result}) Для локального запуска: pip install -r requirements.txt, затем python main.py (сервис на порту 8000) Отправьте запрос: curl -X POST http://localhost:8000/process -H "Content-Type: application/json" -d '{"payload":"Клиент Иванов Иван Иванович, паспорт 4509 123456","payload_id":"check-1"}' Повторный запрос с тем же payload_id вернёт исходную строку (демаскирование)
