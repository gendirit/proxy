# Модуль: API-сервис (`main.py`)

FastAPI-монолит, реализующий контракт `POST /process` для маскирования/демаскирования персональных данных (ПД).

## Назначение

Обрабатывает запросы систем-потребителей: принимает текст с ПД, маскирует его (или демаскирует по `payload_id`), возвращает результат. Обеспечивает идемпотентность, защиту от гонок, метрики и безопасное логирование.

## Эндпоинты

### `POST /process`

Основной контракт. Принимает `{payload, payload_id}`, возвращает `{result}`.

- **Направление** определяется по `payload_id`:
  - первый запрос с новым `payload_id` → маскирование;
  - второй запрос с тем же `payload_id` → демаскирование.
- **Коды ответа:**
  - `200` — успех;
  - `403` — система отключена или не найдена (`X-System-Id`);
  - `429` — перегрузка (не удалось получить блокировку / таймаут), с заголовком `Retry-After`;
  - `422` — ошибка валидации (некорректный JSON или типы полей);
  - `500` — внутренняя ошибка (возвращается как `429`).

### `GET /metrics`

Метрики в Prometheus text-формате:
- `process_requests_total{status}` — счётчик запросов по статусам;
- `process_latency_seconds_sum` / `process_latency_seconds_count` — суммарная латентность;
- `process_detected_total{type}` — счётчик обнаруженных типов ПД;
- `process_429_total` — счётчик перегрузок;
- `process_tokens_total` — суммарное число токенов (приблизительно `len(payload)//4`).

### `POST /v1/chat/completions`

Демонстрационный LLM-прокси (без сетевых вызовов). Принимает `{messages}`, маскирует текст в режиме токенизации, прогоняет через `mock_llm`, детокенизирует ответ. Возвращает `{result, masked_prompt}`.

## Ключевые компоненты

### `StateStore`

In-memory хранилище записей с TTL и LRU-эвакуацией.
- `TTL_SECONDS = 3600` — время жизни записи;
- `MAX_RECORDS = 100000` — максимум записей;
- хранит пары «оригинал ↔ маска» по `payload_id`;
- блокировки на `payload_id` обеспечивают идемпотентность и защиту от гонок.

### `ProcessService`

Основная логика обработки:
- `_allowed_types()` — фильтрация типов ПД по конфигу системы;
- `_allow_unmask()` — флаг разрешения демаскирования;
- `process()` — блокировка на `payload_id`, определение направления, кэширование;
- `_run_mask()` — маскирование (для текстов > 2000 символов — в отдельном потоке через `asyncio.to_thread`).

### Метрики

Глобальный словарь `_metrics` обновляется без блокировки в горячем пути (однопоточный asyncio event loop). Чтение метрик (`GET /metrics`) защищено `_metrics_lock`.

### Безопасное логирование

- `RedactFilter` — заменяет типовые ПД на `[REDACTED]` в сообщениях лога;
- `_log_json()` — логирует структурированный JSON **без** исходного и маскированного текста (только `payload_id`, `status`, `direction`, `detected_types`, `entity_count`).

## Конфигурация

- `CONFIG_PATH = "config.json"` — путь к конфигу;
- `_DEFAULT_SYSTEM` — дефолтные настройки системы;
- `_resolve_system()` — выбор системы по `X-System-Id` или `default_system`.

## Selftest

`python main.py --selftest` — 10 проверок:
1. пустой payload → пустой результат;
2. первый запрос возвращает маску;
3. повторный запрос с тем же оригиналом → та же маска;
4. запрос с маской → оригинал;
5. отсутствие ПД → маска равна оригиналу;
6. два одновременных запроса с одним `payload_id` → одинаковый результат;
7. запись не обновляется в спорном случае;
8. фильтрация по `pii_types`;
9. запрет демаскирования (`allow_unmask=false`);
10. одинаковый payload с разными `payload_id` → одинаковая маска.

## Запуск

```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --workers 1
python main.py --selftest
```
